A real steam locomotive thunders out of a tiny model railway on a table —
a full-size train bursting from a toy world, steam everywhere, a miniature
engineer waving at the table's edge. An entry for
[make.fun's ai-excited-01 bounty](https://make.fun/bounty/ai-excited-01),
"Make the AI judge excited".

`main.ts` writes `entry.png` byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output`).
